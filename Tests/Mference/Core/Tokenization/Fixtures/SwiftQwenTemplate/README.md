# Swift-Qwen template fixture

Chat template from `ukisai/Swift-Qwen3.8-27b`, revision
`1b30aaaf753fe5c1cb51ada2ea0367a53445359c`. Upstream attribution and license:
https://huggingface.co/ukisai/Swift-Qwen3.8-27b/tree/1b30aaaf753fe5c1cb51ada2ea0367a53445359c
(Swift Open License 1.0, as described by the source model card).
The fixture adds a final newline; all source template text is unchanged.

The fixture uses the existing synthetic ChatML byte vocabulary, not model
weights. Oracle renders are generated by Python Jinja2, independently of
the Swift renderer, using `Scripts/swift_qwen_template_oracle.py`.
