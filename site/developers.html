Get Mference

Developers

Open, local, and yours to build on.

Mference runs on its own Swift and Metal inference engine, with llama.cpp linked in for GGUF models. The same engine powers the app, a local OpenAI-compatible server and a command-line tool.

Get started

Build the app in four commands.

Mference is pre-release, so there is no signed download yet. You need an Apple Silicon Mac with macOS 26 or later and Xcode 26 (or its Command Line Tools).

On first run the app helps you pick a model. Quick, Deep and Bonsai download from inside the app.

# clone, fetch the bundled search engine once, build and open
git clone https://github.com/NeelM0906/Mference.git
cd Mference
App/Scripts/searxng/prepare.sh --fetch
App/Scripts/run.sh

More models

Install the other five.

Qwen 3.6, MiniCPM5 (2B and 1B), Maple and Inkling 2 Mini install from the terminal. The installer streams each pinned checkpoint without staging the whole source, and the app finds the result in ~/llm-models on its own.

# or --model minicpm5 / minicpm5-1b / maple / inkling2mini
swift run -c release MferenceRepack \
  --model qwen36 --output ~/llm-models/qwen36.gturbo
# add --resume to continue an interrupted install

Under the hood

One engine, three ways in.

MferenceEngine

One API for every model, with two backends: Mference's own runtime for .gturbo installs and in-process llama.cpp for GGUF files. Embed it in your own Swift app.

Engine API →

Local server

An OpenAI-compatible server bound to 127.0.0.1. In library mode it serves every installed model from one process, swapping the resident model in place.

Server guide →

CLI

Server

Point your own tools at your Mac.

Anything that speaks the OpenAI chat API can talk to a model on your Mac. The server has no authentication of its own, so it stays on the loopback address unless you choose your Tailnet.

Run one model process at a time: not alongside the app, which already holds its model.

swift build -c release --product MferenceServer
.build/release/MferenceServer \
  --model ~/llm-models/qwen36.gturbo \
  --port 8080 --max-context 16384

# then, from any client
curl http://127.0.0.1:8080/v1/models
